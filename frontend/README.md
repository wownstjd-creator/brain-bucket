# BrainBucket 프론트

대자보 이미지 중심 모바일 화면 시제품입니다. React + TypeScript + Vite로 구성합니다.
백엔드 API, 실제 로그인, 서버 저장, 승인 처리와 DB는 연결하지 않았습니다.

## 실행

Node.js 22.12 이상(또는 20.19 이상)이 필요합니다.
탐색기에서 `실행하기.cmd`를 더블클릭하면 개발 서버를 시작합니다. 터미널을 계속 열어두고 http://localhost:5174/ 에 접속하세요. PowerShell에서는 `./실행하기.ps1`을 실행하거나 아래 명령을 사용할 수 있습니다.

```powershell
npm install
npm run dev
```

- 화면: http://localhost:5174/
- 같은 Wi-Fi의 휴대폰: 터미널 Network 주소로 접속 (방화벽/네트워크 설정에 따라 달라집니다)
- 종료: 터미널에서 Ctrl+C
- 검사/빌드: `npm run build`

## 가능한 화면 체험

- 이미지 중심 대자보 목록, 분류 선택, 검색, 검색 결과 없음
- 상세 정보, 전단 확대, 목록 복귀
- 지난 전단 목록과 연도·분류·검색 필터
- 작성/수정 폼, 기기의 이미지 선택, 입력 내용 미리보기
- 내 대자보의 작성 중·승인 대기·반려 상태 예시
- 로그인·회원가입 화면 (인증 요청을 보내지 않음)

작성 내용은 현재 화면의 메모리에만 존재하고 다른 화면으로 이동하면 사라집니다.
임시 저장·승인 요청 버튼은 API 연결 전이므로 비활성화되어 있습니다.
샘플 전단은 실제 행사 정보가 아닙니다. 아카이브 샘플 이미지는 기존 샘플의 재사용입니다.

## 구조

```text
src/App.tsx                    화면과 브라우저 내부 이동
src/styles.css                 모바일 디자인
src/types.ts                   프론트 화면용 데이터 형식
src/data/boardRepository.ts    샘플 데이터 공급 계층 (향후 API 변환 연결 지점)
public/posters/                샘플 전단 SVG
```

해시 경로를 사용하므로 새로고침과 브라우저 뒤로가기가 가능합니다.
API/인증 처리가 없는 상태라 작성 화면은 로그인 없이 체험할 수 있습니다.
이는 최종 접근 권한 정책이 아닙니다. 백엔드 연결 때 실제 인증/권한을 적용해야 합니다.

## 백엔드와 확정할 부분

- 공개 목록/상세/이미지/아카이브 API
- 이미지 업로드 제한, 담당자 승인 증빙 제출 방식
- `deadlineAt` 의미와 별도 게시 종료일 필드
- 분류 코드, 날짜/시간 기준, 목록 페이지 형식
- 프론트 개발 서버와 연결할 프록시/CORS 방식

현재 화면 필수 항목(이미지 안내/제목/주최자/게시 종료일)은 디자인 초안입니다.
필드명과 규칙이 백엔드 계약으로 확정된 것은 아닙니다.
이 프로젝트에서 수정한 범위는 frontend 폴더뿐이며 기존 백엔드와 DB 설정을 사용하지 않습니다.
