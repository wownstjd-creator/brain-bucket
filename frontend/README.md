# BrainBucket 프론트 — 사진으로 등록하기

## 현재 작업

- 기존 화면 보존 브랜치: `front-dev`
- 사진 보정·OCR 기능 브랜치: `codex/poster-capture`
- 코드 수정 범위: `frontend`만. 백엔드/DB 코드는 수정하지 않았습니다.

## 실행

1. `실행하기.cmd` 더블클릭 또는 이 폴더에서 `npm install` 후 `npm run dev`.
2. http://localhost:5174/#/upload 접속.
3. 이전 개발 서버가 켜져 있으면 Ctrl+C로 종료하고 다시 실행합니다. 새 프록시 설정을 읽어야 합니다.
4. 실제 로그인/저장을 쓰려면 저장소 최상위 README에 따라 백엔드와 MySQL을 실행합니다.

프론트 개발 서버와 `npm run preview`는 `/api` 요청을 `http://127.0.0.1:8080`으로 전달합니다.
배포 환경에서는 동일한 API 경로 라우팅을 별도로 구성해야 합니다.

## 동작

1. 파일 선택 또는 사진 촬영. JPG/PNG/WebP 20MB 이하 지원. PDF/HEIC 미지원.
2. 네 모서리를 직접 지정. 터치/마우스 드래그 및 방향키 지원.
3. 원근 보정으로 반듯하게 펴기, 선택적으로 밝기·대비 보정.
4. 한국어/영어 OCR → 제목·주최·장소·신청 링크·날짜를 제안.
5. 원본과 비교하고 직접 수정, 확인 체크.
6. 로그인 후 **확인한 텍스트를 임시 저장**.

카메라 입력은 휴대폰/브라우저에 따라 카메라 또는 사진 선택기가 열릴 수 있습니다.
넓은 화면에서는 사진과 입력 폼을 좌우로, 모바일에서는 위아래로 배치합니다.
OCR은 Tesseract.js 6.0.1로 브라우저에서 처리하며 사진을 외부 OCR 서버에 보내지 않습니다.
최초 실행 때 엔진과 한국어/영어 언어 모델은 CDN에서 다운로드하므로 인터넷 연결이 필요합니다.
인식 취소, 실패 후 재시도, 원문 직접 수정도 가능합니다. 디자인이 복잡하거나 흐린 포스터는 정확도가 낮을 수 있습니다.
AI 해상도 향상 또는 자동 모서리 탐지는 포함하지 않았습니다.

## 날짜 처리

- 행사, 접수/신청 마감, 명시된 게시 기간을 구분합니다.
- 연도가 없으면 화면에 표시한 기준 연도로 제안하며 확인 경고를 표시합니다.
- 날짜가 잘못되었거나 종류를 구분하지 못하면 자동 입력하지 않습니다.
- 시간이 없으면 임의로 자정으로 정하지 않습니다. API 저장 전 작성자가 시간까지 입력하거나 날짜를 비워야 합니다.
- 행사 날짜를 게시 종료일로 대신 사용하지 않습니다.
- 자동으로 채운 항목에는 근거 문구를 표시합니다. 사용자가 직접 수정한 값은 재인식해도 덮어쓰지 않습니다.

## 연결된 백엔드 API

- GET `/api/auth/csrf`, GET `/api/auth/me`
- POST `/api/auth/signup`, `/api/auth/login`, `/api/auth/logout`
- POST `/api/posts` (DRAFT 생성)
- PUT `/api/posts/mine/{postId}` (같은 작성 화면에서 다시 저장)

세션 쿠키를 사용하고 변경 요청마다 CSRF 토큰을 다시 받습니다. 실패한 저장 요청을 자동 재전송하지 않습니다.
아직 백엔드에 없는 이미지 업로드·게시 기간 저장·승인 요청 API를 임의로 호출하지 않습니다.
**게시하기 버튼은 비활성화되어 있으며, 임시 저장을 공개 게시로 표시하지 않습니다.**
원본/보정 사진과 게시 시작·종료일은 API 저장에서 제외됩니다. 필요한 보정본은 다운로드하세요.
화면에서 벗어나면 메모리에 있던 사진과 입력 내용은 사라집니다.
기존 공개 목록·아카이브·내 대자보 화면은 아직 샘플 데이터입니다.

## 백엔드에 필요한 다음 작업

1. 이미지 업로드 API와 파일 ID 또는 URL 응답
2. 게시 시작/종료 필드와 `deadlineAt` 의미 확정
3. 임시 게시물에 이미지 연결, 승인 요청 API
4. 담당자 승인 후 공개 목록/상세 조회
5. 승인 증빙과 원본/보정본 보존 정책

## 검증

- `npm run build`: TypeScript 검사와 배포 빌드
- Node.js 22.18 이상에서 `npm test`: 날짜 추출/원근 변환/세션·CSRF 요청 등 단위 테스트
- 선명한 한국어 테스트 이미지에서 실제 OCR 인식 확인
- 실제 스마트폰 촬영/터치 조작과 실행 중인 Spring/MySQL에 대한 저장은 별도 통합 확인 필요
