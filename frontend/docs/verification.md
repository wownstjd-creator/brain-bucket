# 통합 검증 — 2026-10-10

## 수행한 검증

- Flyway 자동 업데이트: 실제 MySQL8.0.46에서 세 DB 상태, 데이터 보존, 중복 적용 방지, Boot/JPA 시작 검증. 세부 내용은 docs/database.md.
- 회원가입 HTTP 201 및 신규 계정 로그인, 백엔드 테스트 총4개 통과, JAR 패키징 성공.

- Java21 Maven 컴파일.
- H2 MySQL 모드에서 서비스/파일/DB 트랜잭션 통합 테스트: 등록, 증빙 필수, 권한, 예약 비공개, 공개 검색, 내림·복구, publishedAt 유지, APPROVED→DRAFT, 오래된 version409, 실패 후 기존 파일 유지, 역사 이미지 바이트 보존, 반려·재요청, 스크랩 중복/계정 분리/숨김 제외.
- 실제 임시 HTTP 서버: 로그인·세션·CSRF, 비로그인401, 일반 사용자 ADMIN403, CSRF없는 쓰기403, 공개 상세, 증빙 비로그인 차단, 세션 내 조회수 중복 방지, 스크랩 저장·해제.
- 프론트 TypeScript 검사·Vite production build, 13개 기존/갱신 테스트 통과.

Java 테스트는 workflow 1개, HTTP security 1개, contextLoads 1개로 총3개이며 workflow 내부에 여러 시나리오와 assertion을 포함합니다. 테스트 DB와 계정은 H2에만 생성됩니다.

## 아직 수행하지 않은 검증

- Windows에서 scripts/run.ps1 실행 확인. 자동 Flyway 업데이트는 별도 MySQL8.0.46에서 빈 DB·구버전 DB·수동 적용 DB 세 경우 모두 통과.
- 실제 브라우저의 화면 배치·로그인 후 스크랩 UI, 카메라·OCR 모델 다운로드·휴대폰 실기기.
- 동시 요청 스트레스·실제 저장소 장애/커밋 결과 불명 실험.
- Docker image/compose 실행, 외부 서버 HTTPS 배포.
